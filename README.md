# zamanayaz.github.io

Portfolio for Zaman Ayaz. One self-contained `index.html`: no build step, no external CSS, JS, font or image requests — open the file and it works.

The page uses a cut-paper visual system: torn edges, card-stock controls, grain and fibre textures, and a warm paper palette with a yellow accent. Chillax and Geist Mono are embedded as base64, along with the Sabzi Mandi screenshot as WebP, so the file stays self-contained.
